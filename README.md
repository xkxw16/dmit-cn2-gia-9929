# CN2 GIA 和 9929：从路由识别到按宽带挑线路，一次把两条精品回国线弄明白

搜「CN2 GIA 和 9929」的人，基本卡在同一个问题上：两条线都被叫做高端精品，钱花得不便宜，到底该买哪条。

常见答案是「电信选 CN2 GIA，联通选 9929」。这个结论没错，但只说了一半。它没解释为什么有人买了标着 CN2 GIA 的机器，`traceroute` 里却跑出一串 `202.97`；也没解释为什么联通用户在国内高峰时段反而觉得 9929 更稳。要弄明白该选谁，得先知道这两条线分别属于谁、路由长什么样、以及你自己的宽带在哪一家。

## CN2 GIA 和 9929 根本不属于同一家运营商

这是最容易被忽略的一点。它们不是同一张网的高配版和低配版，而是两家运营商各自独立建的通道。

**CN2 GIA 属于中国电信。** CN2 是电信的下一代承载网，AS 号 AS4809，是一张物理上独立的网络，有自己的路由器、传输设备和国际海缆资源，不和普通公众网络抢带宽。GIA 是它内部最高的一档，特征是去程和回程都走 CN2 节点，路由里到处是 `59.43.x.x`。同一张网里还有一档 CN2 GT，只在国际出口切进 CN2，国内段仍然走 163 骨干网，所以路由里会先看到 `59.43`，进国内之后变成 `202.97`。

**9929 属于中国联通。** 正式名称是 CUII（China Unicom Industrial Internet），业内常叫「联通 A 网」，前身是网通官商网，面向政企和高端客户。国内段用独立的 A 网路由器转发，绕开 169 骨干网；国际段通常由 AS10099 承担，所以 9929 线路常见的架构是「AS9929 + AS10099」两段组合。

顺带说一个容易搞混的点：AS10099（CUP，China Unicom Premium）不是一条独立的网络技术，它更像联通精品网的国际品牌，国际段走 AS10099，进入国内之后接 AS9929。看到商家同时标 9929 和 CUP，通常指的是同一套链路的两段。

## 两条线的差别到底体现在哪里

公开测评里被反复引用的数据大致是这个量级，可以作为参考，但别当成保证值——线路表现会随时间和地区浮动。

| 对比项 | CN2 GIA | AS9929 |
| --- | --- | --- |
| 归属 | 中国电信 | 中国联通 |
| 关键 AS | AS4809 | AS9929（国内）+ AS10099（国际） |
| 路由特征 | 全程 `59.43.x.x`，不出现 `202.97` | 出现 AS9929 节点，常见 `218.105`、`210.51` 段 |
| 主要服务对象 | 电信用户最优，对联通/移动靠网间互联 | 联通用户最优 |
| 美西方向延迟参考 | 约 120–150ms | 约 150–180ms |
| 晚高峰丢包 | 常在 0.1% 量级 | 常见 0.1%–1% |
| 价格定位 | 通常是普通线路的 3–5 倍 | 略低于 GIA，但仍远高于普通线路 |

香港和日本方向的差距会缩小甚至反转。有测评数据显示，9929 在日本方向白天非高峰可以低到 35–45ms，晚高峰也只涨到 50–60ms；而两者在香港方向都能压到几十毫秒，基本分不出高下。真正拉开差距的是美国西海岸这条长链路。

## 按自家宽带选，比按「哪条线更强」选更靠谱

「谁更好」这个问题本身不太成立，因为两条线的优化对象不同。判断顺序应该是先看自己用什么宽带，再看业务主要面向谁。

**电信用户。** 首选 CN2 GIA，全程在电信自己的通道里跑，不需要跨网交接。用 9929 也能用，实测洛杉矶 9929 机器对电信用户的平均延迟大概 169ms，比普通线路的 200ms+ 强不少，但它必须多走一道跨网交换：数据从美国出来走联通国际骨干，到上海或广州的 9929 节点后才交给电信网络。多出来的这段跳数和不确定性，就是体验差距的来源。

**联通用户。** 优先 9929。这条线本来就是给联通自家用户修的路，路径最短、优先级最高。有个说法是 9929 的用户密度低，所以在某些时段稳定性甚至压过 CN2 GIA——这个判断在实测里能找到支持，但别把它当成通例，跨省结算之后网间拥塞的变化已经让不少老经验失效了。

**移动用户。** 两条都不是为你优化的。移动的对应产品是 CMIN2（AS58807），能选 CMIN2 就别绕路。

**三网都要覆盖。** 现实里大多数商家卖的不是纯 9929 或纯 GIA，而是混合方案：回程按运营商分流，电信走 CN2 GIA、联通走 9929、移动走 CMIN2。这种「三网优化」比单线方案贵，但对建站或者面向全国用户的业务，通常比赌某一家运营商更划算。

## 下单前先自己验一遍路由

商家在宣传页写什么是一回事，机器实际怎么走是另一回事。这三个坑在圈里出现频率很高。

第一，标着 GIA 实际是 GT。判断方法很直接：在机器上对本地 IP 做追踪，全程每一跳都是 `59.43.x.x`，才是 CN2 GIA；国际段是 `59.43`、进国内某一跳变成 `202.97`，那就是 GT。用 `nexttrace` 或 `mtr` 都能看出来：

bash
mtr -r -c 100 你的本地IP


第二，标着 9929 其实是 4837。真正的 9929 路由里必须出现 AS9929，如果整条路径只有 AS4837 或 AS4134，那说明你拿到的是普通骨干网。极低价格的「9929 套餐」大概率是超售或线路混用，因为 9929 的带宽成本本来就是普通国际带宽的数倍。

第三，IPv6 不一定跟着 IPv4 走。电信 AS4809 的境内段没有完成 IPv6 建设，目前只提供境外段的 IPv6 互联，跨境段和境内段实际仍走 AS4134。所以有些 CN2 GIA 机型 IPv4 走 CN2 GIA，IPv6 却走的是 9929/CMIN2 的负载均衡。买之前看清楚商家在 IPv6 上的说明，不然你按 GIA 付费、实际用到的可能是另一条路。

另外提醒一句：测路由别只测一次。晚高峰（20:00–23:00）和白天完全是两个世界，有条件就跑 24 小时看波动曲线。

## 两点购买建议

DMIT 支持支付宝、PayPal 和信用卡付款，国内用户不用折腾支付渠道。官网购物车页有明确的路由说明，下单前建议先看一眼当前库存在哪个机房、哪个代平台，同一档套餐在不同平台上价格是有差的。

优惠码方面，社区整理里流传的主要是两类：一类是「非月付循环折扣」，名字里带 NON-MONTHLY、RECURRING 这种字样，季付及以上才生效；另一类是节日活动码。比如 `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF` 和 `Lite-Annually-Recur-30OFF` 这两个在多个渠道反复出现过，但优惠码有生命周期，随时可能失效或调整适用范围。结算页有验证入口，输入后能立刻看到折扣是否生效、不匹配的周期会直接报错——别嫌麻烦，这一步花不了十秒钟。

至于 CN2 GIA 和 9929 本身，它们都值得买，前提是你买对了那一档。花 GIA 的钱拿到 GT 的路由，或者花 9929 的钱拿到 4837 的链路，才是真正让人难受的事。买完跑一遍 `mtr`，比看十篇宣传文都管用。
